# 研究记忆与事件日历

## 研究记忆

- 每份用户材料生成独立 JSON 记录，以内容哈希标识，不覆盖旧记录。
- 默认战术观点有效 30 天，结构性框架有效 180 天；材料明确给出期限时应在记录中修订为原期限。
- `author_views` 是作者观点，不是系统确认事实。`verified_facts` 也必须在当次 provider 数据中重新验证后才能写作当前事实。
- 日报按板块标题、资产代码、别名和主题检索仍有效记录，最多注入八条，避免旧材料淹没当日证据。

## 来源边界

- `primary`：官方、监管、公司公告、交易所，可支持已确认事实。
- `professional_media` / `specialist_media`：可支持媒体报道或具名观点。
- `aggregator`：只用于发现和交叉核验。
- `snippet_only` 表示系统未读取正文，只能使用候选标题和摘要中可见的信息。

## 未来事件

- 只接受未来七天内具有明确单日日期的结构化事件。
- 周度范围、相对日期和泛泛风险不进入读者日历。
- 保存香港时间、来源原时区、全天标记、确认状态与最后核验时间。
- PDF 只显示 `confirmed` 事件；`tentative` 候选保留在 JSON 供操作审计。
